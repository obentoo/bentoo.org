Notes

The original bentoo-logo.svg ships with the project. Variations 02–09 are derived via CSS filters, SVG transforms, or re-composition — no external image assets required. The TikTok effect uses three stacked img layers with color filters and mix-blend-mode: screen. The pixel art (07) is rendered with a CSS grid and a JavaScript pattern array. Hover the TikTok and Glitch variants for animation.
